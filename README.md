# MIDIKeys

Verwandelt die Computer-Tastatur in ein MIDI-Keyboard: Klaviatur auf der
Home-Reihe, Oktavwechsel, Sustain, Akkorderkennung, Piano-Ton oder MIDI an
die DAW.

| Plattform | Ordner | Technik |
|---|---|---|
| **macOS** 14+ | [`mac/`](mac/README.md) | Swift 6, Menüleisten-App, CoreMIDI |
| **Windows** 10/11 | [`windows/`](windows/README.md) | C# / .NET 10, Tray-App, winmm + loopMIDI-Treiber |

Gemeinsame Grafiken (Logo, App-Icons) liegen in [`icons/`](icons/).
